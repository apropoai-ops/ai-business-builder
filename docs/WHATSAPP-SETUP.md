# מדריך חיבור סוכן הוואטסאפ (WhatsApp Business Cloud API)

מדריך מדויק, צעד-אחר-צעד, לחיבור מספר וואטסאפ אמיתי לסוכן ה-AI של הפלטפורמה.
נכתב מול הקוד בפועל (2026-07-20): הכתובות, השדות והטוקנים כאן הם בדיוק מה שהמערכת מצפה לו.

## איך זה עובד (תמונה כללית)

```
לקוח שולח וואטסאפ → Meta Cloud API → Webhook: https://apropo.business/api/whatsapp/webhook
→ המערכת מזהה את העסק לפי Phone Number ID → סוכן ה-AI מנסח תשובה (לפי הפרופיל,
המטרות וה-FAQ שהוגדרו) → נשלחת תשובה דרך Graph API → הכול נשמר בטאב "שיחות" + נפתח ליד ב-CRM
```

## דרישות מקדימות

1. **חבילה**: הסוכן זמין בחבילת חנות (business) או כתוספת בתשלום `whatsapp_agent`.
2. **מספר טלפון "נקי"**: המספר שמחברים חייב לא להיות רשום באפליקציית וואטסאפ רגילה/עסקית.
   (לבדיקה ראשונית אפשר להשתמש במספר הבדיקה החינמי של Meta — ראו שלב 3.)
3. חשבון פייסבוק + Meta Business (נוצר אוטומטית בתהליך אם אין).

## שלב 1 — יצירת אפליקציית Meta

1. היכנסו אל https://developers.facebook.com → `My Apps` → `Create App`.
2. בחרו סוג **Business** → תנו שם (למשל "Apropo WhatsApp") → צרו.
3. במסך האפליקציה, תחת Add products: מצאו **WhatsApp** ולחצו `Set up`.
   בתהליך תתבקשו לקשר/ליצור Meta Business Account.

## שלב 2 — App Secret (קריטי לאבטחה)

1. באפליקציה: `App settings → Basic` → העתיקו את ה-**App Secret** (לחצו Show).
2. **חובה לעדכן את המשתנה `WHATSAPP_APP_SECRET` ב-Vercel לערך הזה** — המערכת מאמתת
   חתימה (HMAC-SHA256) על כל הודעה נכנסת; אם הסוד לא תואם לאפליקציה ששולחת, הודעות יידחו.
   (מסרו את הערך ל-Claude או עדכנו ב-Vercel → Project → Settings → Environment Variables, ואז Redeploy.)

## שלב 3 — מספר טלפון + Phone Number ID

במסך `WhatsApp → API Setup`:

1. תחת **From** תראו מספר בדיקה (Test number) שמגיע חינם — מצוין ל"בדיקה מעמיקה":
   אפשר לשלוח ממנו לעד 5 מספרים מאומתים (הוסיפו את המספר האישי שלכם תחת **To** ואמתו ב-SMS).
2. העתיקו את ה-**Phone Number ID** (מספר בן ~15 ספרות מתחת למספר הטלפון) — לא את מספר הטלפון עצמו.
3. **למעבר למספר אמיתי** (אחרי שהבדיקות עברו): `WhatsApp → API Setup → Add phone number`,
   מלאו פרטי עסק, אמתו את המספר ב-SMS/שיחה. המספר האמיתי מקבל Phone Number ID חדש —
   עדכנו אותו בפלטפורמה (שלב 6).

## שלב 4 — טוקן גישה קבוע (System User Token)

הטוקן שמוצג ב-API Setup הוא זמני (24 שעות) — טוב לבדיקה, לא לייצור. לטוקן קבוע:

1. https://business.facebook.com → `Settings` (גלגל שיניים) → `Users → System users`.
2. `Add` → שם (למשל "apropo-bot") → תפקיד **Admin** → צרו.
3. אצל המשתמש: `Add assets` → Apps → בחרו את האפליקציה שיצרתם → הפעילו **Manage app** → שמרו.
4. `Generate new token` → בחרו את האפליקציה → Expiration: **Never** → סמנו הרשאות:
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`
5. צרו והעתיקו את הטוקן (יוצג פעם אחת בלבד — שמרו אותו).

## שלב 5 — הגדרת ה-Webhook ב-Meta

במסך `WhatsApp → Configuration`:

1. **Callback URL**:
   ```
   https://apropo.business/api/whatsapp/webhook
   ```
2. **Verify Token**: הערך מוצג עם כפתור העתקה בפלטפורמה — עסק → וואטסאפ → טאב **"חיבור אמיתי"**.
   הדביקו אותו ב-Meta ולחצו `Verify and save` (חייב לעבור ✓).
3. תחת **Webhook fields** לחצו `Manage` → הפעילו Subscribe לשדה **`messages`** (זה השדה היחיד שנדרש).

## שלב 6 — חיבור בפלטפורמה

בעסק הרלוונטי → **וואטסאפ** → טאב **"חיבור אמיתי"**:

| שדה | מה מזינים |
|---|---|
| Phone Number ID | מהשלב 3 |
| Access Token | הטוקן הקבוע מהשלב 4 |
| מספר תצוגה (אופציונלי) | המספר בפורמט בינלאומי, למשל `+972501234567` — משמש גם לכפתור הוואטסאפ הצף באתר |

לחצו **"חבר והפעל"**. בנוסף ודאו בטאב "סוכן וסימולטור" שהסוכן **מופעל** (מתג enabled) ושה-greeting/מטרות/FAQ מוגדרים — זה מה שמזין את התשובות.

## שלב 7 — בדיקה מעמיקה

1. שלחו הודעת וואטסאפ מהטלפון האישי (שאומת בשלב 3) אל מספר הבדיקה.
2. תוך שניות אמורה לחזור תשובת AI בעברית לפי אופי העסק.
3. בפלטפורמה: טאב **"שיחות"** — ההתכתבות כולה נשמרת שם; ב-**CRM** נוצר ליד חדש מהמספר.
4. תרחישים לבדיקה: שאלת מחיר, שאלה מה-FAQ, בקשת תיאום תור, הודעה לא קשורה (לוודא שהסוכן מחזיר לנושא).

## פתרון תקלות

| סימפטום | סיבה שכיחה | פתרון |
|---|---|---|
| `Verify and save` נכשל ב-Meta | Verify Token לא תואם | העתיקו שוב מהטאב "חיבור אמיתי" (בלי רווחים) |
| ההודעה נשלחת אך אין תשובה | `WHATSAPP_APP_SECRET` לא תואם לאפליקציה | עדכנו את המשתנה ב-Vercel ל-App Secret של האפליקציה שלכם + Redeploy |
| אין תשובה אחרי ~יום של עבודה תקינה | טוקן זמני (24ש') פג | עברו לטוקן System User קבוע (שלב 4) |
| תשובה לא נשלחת לנמען מסוים | במצב Test אפשר לשלוח רק ל-5 מספרים מאומתים | הוסיפו את הנמען ב-API Setup → To, או עברו למספר אמיתי |
| הסוכן לא עונה אבל ההודעות נשמרות | הסוכן כבוי (enabled=false) או חריגה ממכסה (60 תשובות/שעה לעסק) | הפעילו את המתג בטאב הסוכן / המתינו |

## מגבלות ועלויות בצד Meta

- שיחות שירות (הלקוח פנה ראשון) — לרוב בחינם במסגרת המכסה החודשית של Meta; שיחות תבנית יזומות בתשלום. פרטים: https://developers.facebook.com/docs/whatsapp/pricing
- קצב: המערכת מגבילה 60 תשובות AI לשעה לעסק (הגנת עלויות), ושומרת 12 הודעות אחרונות כהקשר לשיחה.
