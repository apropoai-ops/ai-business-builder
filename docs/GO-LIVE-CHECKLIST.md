## 1️⃣ דומיין משלך
**למה:** אמינות שיווקית + נדרש לאימות Resend (§4). כתובת יפה במקום `…vercel.app`.

**צעדים:**
1. קנה דומיין — הכי נוח דרך **Vercel → Domains** (או Namecheap/Cloudflare).
2. חבר לאפליקציה ב-Vercel → Project → Domains.
3. אם שינית דומיין ראשי: עדכן `NEXT_PUBLIC_APP_URL` ב-Vercel + Site/Redirect URLs ב-Supabase + Webhook URL ב-Stripe.

**עלות:** ~**₪50–60/שנה** (.com/.co.il).

## 2️⃣ Vercel Pro
**למה:** תוכנית Hobby **אוסרת רשמית שימוש מסחרי**. ברגע שגובים כסף — חובה Pro.

**צעדים:** Vercel → Settings → Billing → Upgrade to Pro.

**עלות:** $20/חודש = **~₪890/שנה**.

## 3️⃣ Stripe Live — מנויי הפלטפורמה (לגבות מבעלי עסקים) ⭐ החסם האמיתי להכנסה
**למה:** כרגע Sandbox (כסף מדומה). זה מה שמאפשר לגבות ₪499/799/999.

**צעדים:**
1. Stripe → **Switch to live account** → השלם **Activate account** (פרטי עסק, ח.פ/ע.מ, חשבון בנק).
2. צור מחדש ב-Live: `sk_live_…` + 3 מחירים (ILS חודשי חוזר) + Webhook ל-`https://<דומיין>/api/webhooks/stripe` (אירועים: checkout.session.completed, customer.subscription.updated/deleted) → `whsec_…`.
3. עדכן ב-Vercel את 5 המשתנים בערכי Live: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_STARTER/PRO/BUSINESS`.
4. הדלק קבלות ב-Live: Settings → Customer emails → Successful payments + Refunds.
5. `npx vercel deploy --prod --yes`.

**עלות:** אין מנוי. עמלה ~**2.9% + ₪1.2** לעסקה — נתח מההכנסה, לא הוצאה קבועה.

---

## 4️⃣ Stripe Live — סליקת החנות (לקוחות הקצה משלמים לעסק)
**למה:** היום סליקת הכרטיס בחנות עובדת ב-Test עם חשבון הפלטפורמה. בפרודקשן צריך להחליט איך **כל עסק מקבל את כספו**.

**שתי אפשרויות:**
- **א. מפתח Stripe לכל עסק (פשוט):** כל בעל עסק מדביק מפתח Stripe משלו → הכסף נכנס ישירות אליו. מימוש קל, ללא Connect. *(דורש בנייה קטנה — שדה מפתח לעסק.)*
- **ב. Stripe Connect (SaaS-proper):** הפלטפורמה פותחת חשבון מקושר לכל עסק + עמלת פלטפורמה. עוצמתי, אך מורכב יותר. *(בנייה גדולה יותר.)*

**עלות:** אותה עמלת Stripe (~2.9%+₪1.2). Connect ללא דמי-קבע. **החלטה נדרשת לפני בנייה.**

## 5️⃣ Resend — אימות דומיין (מיילים לכל הלקוחות)
**למה:** היום השולח `onboarding@resend.dev` מגיע **רק** ל-apropo.ai@gmail.com. אחרי אימות — מיילי האישור המותגים (כבר בנויים!) יגיעו לכל לקוח.

**צעדים:**
1. Resend → Domains → Add Domain → הזן את הדומיין מ-§1.
2. הוסף את רשומות ה-DNS (SPF + DKIM) אצל ספק ה-DNS.
3. אחרי אימות → הגדר `RESEND_FROM=noreply@<דומיין>` ב-Vercel + .env.local → פרוס.

**עלות:** Resend חינם עד **3,000 מיילים/חודש**; מעבר לכך $20/חודש (~₪890/שנה).
